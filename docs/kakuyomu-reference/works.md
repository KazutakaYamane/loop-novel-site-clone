## 組み方

### 小説一覧

| 項目 | PC | スマートフォン |
|---|---|---|
| 見出し(「小説」と件数) | 24px、行の高さ 28.8px、太字、`#222` | 画面の上のバーに「ワークスペース」 |
| 「新しい小説を作成」 | 右寄せ。12px 太字、白い文字、地 `#4baae0`、線 1px `#0990cc`、角 3px、内側 8px 10px | 地 `#ddd`、線 1px `#bbb`、文字 `#222` |
| 小説の行 | 上下に 1px `#ddd` 系の線。左に公開状態の札(「未公開」、地 `#ecd5b3` 系)と話数、続けてタイトル(14px 太字) | 13px、内側 14px |

### 小説の設定

| 項目 | PC | スマートフォン |
|---|---|---|
| 見出し | パンくず「小説 > (タイトル) > 編集」、24px 太字 | 同じ形で小さく |
| 連載状態 | 68×60 の 2 つのボタン。選ばれた側は地 `#4baae0`・線 `#0990cc`・白い太字、他方は地 `#f7f6f5`・線 `#eae9e8`・文字 `#666` | 幅を半分ずつ、高さ 44px |
| タイトル | 連載状態の右。30px、高さ 60px、線なし | 「小説タイトル」の見出しの下に、他の欄と同じ入力欄 |
| 区切り | 「種類・ジャンル」「小説情報」の大見出し(16.8px 太字)を左の列に、項目名(14px 太字)を中の列に、入力欄を右の列(幅 682px)に置く。項目の間に 1px の線 | 1 列。大見出しは中央、13px 太字 |
| ジャンル・セルフレイティングの選択肢 | 14px、地 `#eae9e8`、線 2px 透明、角 3px、内側 7px 10.5px。選ばれたものは地と線 `#666`、白い文字、先頭に「✓」 | 13px、内側 6.5px 9.75px |
| 入力欄 | 16px、線 2px `#ccc`、角 3px、内側 7px 10px、高さ 36px(紹介文は 160px) | 幅いっぱい(380px) |
| 案内文 | 14px、行の高さ 21px、`#444` | 12px、`#666` |
| 文字数 | 入力欄の右下、14px、`#999`。超えると赤 | 12px |
| タグの入力欄 | 3 列(幅 221px) | 2 列 |
| 「変更を保存」 | 地 `#4baae0`、白い文字、角 3px。右に「キャンセル」(12px) | 同じ |

## クローンでの扱い

- ワークスペース(`/my`)はカクヨムのダッシュボードではなく、小説一覧の組み方に合わせる(作品の一覧と作成への導線を置く issue のため)。左のメニュー(ダッシュボード、コレクションなど)はクローンに無い機能なので置かない。
- 新しい作品の作成は、要件(AC-F3-1)どおりタイトルと紹介文だけを入れる画面にし、ほかの項目は設定の画面で変える。カクヨムの作成画面にある種類(オリジナル・二次創作など)、コンテスト、自主企画、コレクション、イメージカラー、広告、予約投稿、更新スケジュールは要件に無いので作らない。
- 上限はキャッチコピー 35 文字、タグ 20 文字・8 つ、ジャンル 1 つをカクヨムに合わせる。画面で確かめられなかったタイトルと紹介文の上限は docs/adr/0019 で決める。
- カクヨムは入力を止めずに、文字数の表示と保存のときの確かめで上限を知らせる。クローンも入力欄に `maxlength` を付けず、超えたら文字数の表示を赤くし、保存のときに Laravel の確かめのエラーを項目ごとに表示する。
