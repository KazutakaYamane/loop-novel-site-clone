## クローンでの扱い

- 執筆画面はサイトのヘッダーの中に置く(全画面の編集画面、記法の横のパネル、プレビュー、元に戻す・やり直しは、この issue の要件に無いので作らない)。ボタンの並び(上のバーの右)、ボタンの色と大きさ、線の無いタイトルと本文の欄、タイトルの下の青い線、文字の大きさと行の高さ、右下の文字数をカクヨムに合わせる。
- 欄の名前はカクヨムどおり見た目に出さず、支援技術向けにだけ残す。
- ボタンの文言は要件(下書き保存・公開)に合わせて「下書き保存」「公開する」のままにする。カクヨムの「公開に進む」は公開の設定の画面へ進むボタンで、クローンには公開の設定が無い。
- 話の一覧は、見出し、作成のボタン、50px の行、札、日時の大きさと色をカクヨムに合わせる。章、並び順の編集、チェックボックスはクローンに無い機能なので置かない。見出しは章が無いので「エピソード」にする。
