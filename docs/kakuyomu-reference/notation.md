# カクヨム記法のヘルプとプレビューで確かめた上限

- 採取日は 2026-11-27。未ログインのブラウザーで `/help/entry/notation` を各幅で 1 回開いた。例はこの文書用に作った。
- `notation-help-pc.png` と `notation-help-sp.png` はヘルプの見出しと記事の組み方。ヘルプの文章と既存の例は塗りつぶした。

## ヘルプの規則

| 操作 | 書き方と結果 |
|---|---|
| 自動ルビ | `夜空《よぞら》` のように、読みを二重山括弧で囲んで直後に書く。直前に続く漢字が親文字になる |
| 明示ルビ | `｜夜の空《よぞら》` のように親文字の手前へ `｜` または <code>&#124;</code> を置く。指定した範囲には仮名なども使える |
| 上限 | ヘルプにある上限は親文字 20 文字、ルビ 50 文字 |
| 記号を表示する | `｜《` と書くと、括弧が文字として表示される |
| 傍点 | 強調したい範囲を `《《` と `》》` で囲む。例は `《《月明かり》》` |
| 使える範囲 | エピソード本文専用。改行をまたぐ指定や、同じ範囲へのルビと傍点の重ねがけはできない |

執筆画面の編集サイドバーから、選択範囲を囲む記法を挿入できる。ヨミカキでの空欄、入れ子、長さの例外などの扱いは要件書 F5 に従う。

| ヘルプの表示 | PC 1280×800 | Pixel 7 412×915 |
|---|---|---|
| 記事の本文幅 | 695px | 380px、左右 16px |
| 記事タイトル | 28px 太字、行の高さ 33.6px | 15px 太字、行の高さ 19.5px |
| 小見出し | 23.1px 太字、下に 1px `#ddd` | 15px 太字、線は同じ |
| 本文 | 15.4px、行の高さ 27.72px、`#222` | 13px、行の高さ 23.4px、`#222` |

## 異体字セレクタの確認 (#128)

人間が用意したテスト用セッションで、新規エピソードのプレビューに 22 行の自作入力を入れた。保存・公開はしていない。下の表の各行を SVS と IVS で別々に試した。ルビの有無と親文字・読みの範囲は、プレビューが生成したルビ要素で確かめた。

- `S` は SVS なら U+FE00、IVS なら U+E0100。
- `P` は `葛` に `S` を続けたもの。表の `P×n` はその並びを n 個続ける。記法の間に表記用の空白は入れない。
- 文字数の列はコードポイント数。たとえば `P×10` は漢字 10 個とセレクタ 10 個で 20。

| 対象 | 入力 | 文字数 | SVS・IVS 共通の観測結果 |
|---|---|---:|---|
| 自動ルビ | `葛` + `S` + `城《しろ》` | — | `城` のみに `しろ` が付く |
| 明示の親文字 | `｜` + `P×9` + `あ《よみ》` | 19 | 親文字全体に付く |
| 明示の親文字 | `｜` + `P×10` + `《よみ》` | 20 | 親文字全体に付く |
| 明示の親文字 | `｜` + `P×10` + `あ《よみ》` | 21 | ルビ無し、縦線が残る |
| 明示の親文字 | `｜` + `P×20` + `《よみ》` | 40 | ルビ無し、縦線が残る |
| 明示の親文字 | `｜` + `P×21` + `《よみ》` | 42 | ルビ無し、縦線が残る |
| 読み | `｜しるし《` + `P×24` + `あ》` | 49 | 読み全体が付く |
| 読み | `｜しるし《` + `P×25` + `》` | 50 | 読み全体が付く |
| 読み | `｜しるし《` + `P×25` + `あ》` | 51 | ルビ無し、縦線が残る |
| 読み | `｜しるし《` + `P×50` + `》` | 100 | ルビ無し、縦線が残る |
| 読み | `｜しるし《` + `P×51` + `》` | 102 | ルビ無し、縦線が残る |

両セレクタを 1 コードポイントとして数え、自動ルビの漢字の連続はセレクタ位置で切れる。観測結果は、このケースの要件書 AC-F5-6・AC-F5-14 と一致する。
