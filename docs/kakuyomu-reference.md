# カクヨムの動作・見た目の確かめ方

要件書の5章(見た目をカクヨムに合わせる)と F5(記法)のために、カクヨムの画面を確かめるときの手順と禁止事項。カクヨムは他者が運営する本番のサイトなので、確かめる側の都合より、向こうに迷惑をかけないことを優先する。

## 1. 原則

- **向こうに負荷や変化を与えない**: カクヨムのサーバーに負荷をかける行為、カクヨム上に何かを残す・変える行為は、すべて禁止する。必要なときは、実行する前に止めて人間の承認を得る(4章)。
- **他人の著作物を取得しない**: カクヨムに投稿された作品(タイトル、キャッチコピー、あらすじ、本文、作者名、表紙、レビュー、コメントなど)の内容は、一切取得・保存しない。取得してよいのは、レイアウトと見た目の値(寸法、余白、色、フォントの種類と大きさ、行の高さ)と、カクヨム自身の UI の短い文言(ボタンやリンクの名前)だけ。
- **迷ったらやらない**: この文書に書いていない操作は、禁止として扱い、人間に確かめる。

## 2. 承認なしでしてよいこと

- ブラウザ(Playwright)を 1 つだけ使い、ページを 1 つずつ順に開く。
- 開いたページの見た目の値を `getComputedStyle()` と `getBoundingClientRect()` で読む。
- スクリーンショットを撮る。ただし、他人の作品の内容が写る部分は、撮る前に Playwright の `mask` で塗りつぶす(3章)。
- カクヨムのヘルプ(`/help/` 以下)を読み、規則を自分の言葉でまとめる。文章をそのまま写さない。
- テスト用のアカウントでログインし、ログインが必要な画面(ワークスペース、作品の作成・設定、話の編集)を開いて、見た目の値を読む。入力欄に文字を入れてプレビューを見るところまではよい。保存はしない(4章)。
- ログアウトする。

### 負荷の上限

- ページを開く間隔は 5 秒以上あける。並列に開かない。
- 1 回の確認で開くページは 30 まで。超えそうなら止めて、人間に確かめる。
- リンクをたどって自動で巡回しない。開くページは、確かめたい画面だけを事前に決めてから開く。
- 読み込みに失敗しても、自動で繰り返し開き直さない。1 回だけ開き直し、それでも失敗したら止める。
- `robots.txt` で禁じられているパスは開かない。
- k6 などの負荷試験は、ローカルの自分のアプリにだけ使う。カクヨムには絶対に向けない。

## 3. 他人の著作物を取得しないための手順

- スクリーンショットでは、作品のタイトル、キャッチコピー、あらすじ、本文、作者名、表紙、タグ、レビュー、コメント、ランキングの各行を `mask` で塗りつぶす。塗りつぶしたあとに、画像に作品の内容が残っていないことを確かめてから保存する。
- ページの HTML、テキスト、アクセシビリティツリーを丸ごと保存しない。値を読むときは、要素の寸法・色・フォントだけを取り出す。
- 取り出した値のファイルにも、作品の内容の文字列を入れない(要素を作品のタイトルなどで識別しない。`作品カードのタイトル` のように役割の名前で書く)。
- 作品の中身でしか確かめられない見た目(話ページの本文の組み方、ルビの大きさなど)は、テスト用のアカウントの話の編集画面のプレビューで、自分で書いた文章を使って確かめる。他人の作品の話ページを開いて本文を読まない。
- 誤って作品の内容を取得したら、作業を止め、取得したファイルと会話の記録の該当箇所を人間に伝える。コミットしない。

## 4. 人間の承認が必要なこと(実行する前に止めて承認を得る)

loop の中では、エスカレーション(`AGENTS.md` の「Stopping and escalating」)で人間に渡し、承認の返事があるまで実行しない。承認は 1 回ごとで、同じ種類の操作でも次は改めて得る。

- カクヨム上に何かを残す・変える操作すべて: 作品・話・近況ノートの作成、保存(下書きを含む)、公開、予約公開、削除
- 他の利用者や作品に作用する操作すべて: 応援、★、レビュー、コメント、フォロー、ギフト、誤字報告、通報
- アカウントに作用する操作すべて: プロフィール・設定・パスワードの変更、メール・電話番号の確認、退会
- 2章の負荷の上限を超えること
- 2章に書いていない操作すべて

承認を求めるときは、何を・何回・なぜ行うか、元に戻せるか、カクヨムに何が残るかを書く。

## 5. テスト用のアカウント

- ログインには、人間が用意したテスト用のアカウントだけを使う。
- メールアドレスとパスワードは、リポジトリのルートの `.env.kakuyomu` から読む(`.gitignore` 済み。`KAKUYOMU_EMAIL` と `KAKUYOMU_PASSWORD` を持つ)。

  ```
  KAKUYOMU_EMAIL=
  KAKUYOMU_PASSWORD=
  ```

- 値をコード、テスト、ログ、スクリーンショット、PR、Issue、コミットメッセージに書かない。表示しない(`echo` や `console.log` で出さない)。Playwright の trace や動画にパスワードの入力が残らないよう、ログインの操作中は記録を止める。
- ログイン状態(cookie、storage state)をファイルに保存する場合は、`.gitignore` 済みの `.auth/` にだけ置き、作業が終わったら消す。
- アカウントでログインできない、確認コードを求められる、などのときは止めて人間に渡す。自分で回避しようとしない。

## 6. 残すもの

- 採取した参照は `docs/kakuyomu-reference/` に置く: 塗りつぶし済みのスクリーンショットと、見た目の値(画面ごとの Markdown か JSON)。
- 各ファイルに、採取した日付と、PC・スマートフォンのどちらの幅かを書く。
- この文書の禁止事項に反して取得したものは、ここに置かない。
