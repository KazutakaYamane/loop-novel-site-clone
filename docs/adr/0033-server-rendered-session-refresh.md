# 0033 画面移動後のデモセッションはサーバー描画で確認する

- 状態: 採用
- 日付: 2026-11-28

## 背景

ADR 0032 の案内を開いていた画面でも更新するため、画面移動時にセッションを確認する。Laravel の `GET /api/user` はセッション cookie を応答に付ける。ブラウザーから確認を送ると、遅れて届いた応答がログイン・ログアウト直後の cookie を上書きしうる。#131 の CI では、テストが cookie を消した直後に古いセッションが復元され、次のログイン操作が完了する前にログイン済みの表示が出た。

## 決定

- パスかクエリが変わったら、Next.js の `router.refresh()` で共通レイアウトを更新する。初回はサーバー描画がセッションを確認する。
- 確認にはサーバー側の既存のユーザー取得処理を使う。Laravel の応答の cookie はブラウザーに転送されない。セッションと以前のログインを表す cookie がどちらも無い場合は Laravel を呼ばない。
