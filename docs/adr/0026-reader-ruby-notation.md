# 0026 話のルビを Next.js のサーバーで組み立てる

- 状態: 採用
- 日付: 2026-11-27

## 背景

#127 は AC-F5-1〜5 と AC-F5-13 のルビを、公開された話の本文に表示する。本文の保存方法は ADR 0021、読者向け API は ADR 0024、話ページの寸法は ADR 0025 に従う。ルビの見た目には [プレビューの採取値](../kakuyomu-reference/reading-preview.md)を使う。

## 決定

- `frontend/lib/notation/parseNotation.ts` は、本文を元のテキストと親文字・読みの組に分ける。区切り記号と漢字の連続を順に走査する。縦線の指定は次の山括弧で消費し、ルビが成立した場合に縦線を出力から外す。
- `EpisodeBody` はサーバーで各組を `ruby` と `rt` で描画する。本文、親文字、読みはそれぞれ React に文字列として渡し、ブラウザーに渡る際も文字として扱う。空白と改行は本文の `pre-wrap` で保つ。
- 読みは親文字の上中央に置き、文字の大きさを親文字の半分にする。PC は 8.75px、スマートフォンは 8px になる。

## 結果

- 記法の変換にブラウザー側の JavaScript は要らない。ルビを増やす処理は走査側、表示要素の選択は `EpisodeBody` で扱える。
- ルビ付きの本文を Playwright で要素単位で撮り、PC とスマートフォンで比較する。
