# 0025 読者向けの作品ページ・話ページ・見つからない画面の組み方

- 状態: 採用
- 日付: 2026-11-27

## 背景

#125 は、作品ページ、話ページ、見つからない画面の見た目を #150 の採取値(`docs/kakuyomu-reference/public-work.md`、`reading-preview.md`)に合わせる。ただし、他人の話ページは開かないため、話ページの外枠(作品名、前後の移動、目次へのリンク)には採取値が無い。作品ページの目次の日時や、作品色・操作ボタン(フォロー、応援)は、この要件では持たないデータや機能に当たる。

## 決定

- 作品ページは PC で主列 745px と目次の列 420px の 2 列、スマートフォンでは 1 列にする。見出し、作品名、作者名、紹介部分、詳細の表、目次の行の寸法は `public-work.md` の値を使う。作品色のデータは無いので、40×10px の帯は本文の文字色で描く。目次の行に日時は出さない(読者向け API が返さない)。フォロー・応援の操作は作らない(要件書 7 章)。
- 詳細の表は、執筆状況、ジャンル、タグ、セルフレイティングの順に、値があるものだけを出す。作者名は見出しに出すので表には重ねない。
- 話ページの列(825px)、話タイトル、本文の書体・文字の大きさ・行の高さ・行幅・上下の余白は `reading-preview.md` のプレビューの値を使う。段落と空行は入力どおりに `white-space: pre-wrap` で出す。
- 話ページの外枠は採取値が無いので、次のように既存の採取値へ揃える。作品名へのリンクは作品ページの作者名と同じ 14px・行の高さ 21px・`#666` にして、話タイトルの上に置き、タイトルの上端が列の上から約 107px になるようにする。前の話・目次・次の話は、作品ページの目次の行と同じ 14px・行の高さ 16.8px・高さ 54px のリンクにし、本文の下に 3 列で並べる。
- 見つからない画面は `public-work.md` の案内列・見出し・説明の値を使う。文言は採取した見出しに合わせ、説明は意味を保って自分の言葉で書く。「トップへ」のリンクを置く。

## 結果

- 記法の表示(#127〜#129)は `EpisodeBody` の中に足すので、話ページの外枠の寸法は変わらない。
- 話ページの外枠は参照の無い推定なので、後でカクヨムの話ページを採取できたときは、この ADR を置き換える ADR で直す。
