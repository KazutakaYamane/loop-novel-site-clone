# 0027 スマートフォンのフッターの行の高さを整数にする

- 状態: 採用
- 日付: 2026-11-27

## 背景

トップに新着が入ると、作品の件数によってフッターまでスクロールする必要がある。幅 412px では、行の高さが 17.25px のため、フッターの高さは 84.75px になる。Chromium はスクロール量を整数に丸めるので、画面の下端にあるフッターの文字がスクロールの有無で 0.25px ずれて描画される。

## 決定

スマートフォンのフッターの案内と著作権表示の行の高さには、採取値に最も近い整数の 17px を使う。案内が折り返してもフッター全体の高さが整数になり、幅 412px では 84px になる。
