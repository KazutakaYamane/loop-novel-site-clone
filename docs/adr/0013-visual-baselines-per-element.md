# 0013 見た目の基準画像は確定した要素だけを撮る

- 状態: 採用
- 日付: 2026-11-27

## 背景

マージ後の基準画像(`e2e/visual/__screenshots__/**`)は既存のテストとして保護パスになり、guard が変更を落とす。ページ全体を撮ると、後の issue がそのページに中身を足すたびに既存の基準画像が変わり、その issue は人間の承認待ちで止まる。例えば、ヘッダーの右側には #121・#122 がデモのボタンや「ログイン」を足し、トップの本文には #121・#126・#130 が中身を足す。また、並列に動く他のテストやシードで中身が変わる一覧、デモのユーザー名、時刻を写すと、撮るたびに画像が変わる。

## 決定

- 見た目の比較は、その issue で確定する要素を要素単位で撮る(`expect(locator).toHaveScreenshot()`)。
- 撮る要素の中に、後の issue が中身を足す領域や、実行ごとに中身が変わる領域があれば、`mask` で隠す。
- 後の issue は、自分が足した部分の基準画像を新しいテストとして足し、既存の基準画像は変えない。
- #119 では、ヘッダー(右側の操作の領域 `data-testid="header-actions"` を隠す)とフッターを、PC(`visual-pc`)とスマートフォン(`visual-sp`)で撮る。トップの本文は撮らない。

## 結果

- 隠した領域や撮っていない領域の見た目は、その中身を足す issue の基準画像でだけ確かめられる。
- 確定した要素の外側の位置関係(例えばヘッダーと本文の重なり)は、要素単位の画像では見えない。必要になったら、変わらない範囲を新しいテストで撮る。
