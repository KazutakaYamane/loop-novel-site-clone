# 0034 話の執筆画面はハイドレーション後に操作を受け付ける

- 状態: 採用
- 日付: 2026-11-28

## 背景

#131 の CI で、下書きを作った直後に公開ボタンを押してもリクエストが送られなかった。サーバーから届いたフォームは、操作を処理する React のコードが動く前から入力とクリックを受け付けていた。

## 決定

- 新規・既存の話が共用する `EpisodeForm` は、タイトル・本文の欄と下書き保存・公開のボタンを、サーバー描画時に無効にする。送信中は引き続き送信ボタンを無効にする。
- `useSyncExternalStore` のサーバーとクライアントのスナップショットを使い、React がハイドレーションを終えてクライアントの値を反映したら操作できるようにする。クライアントで画面を移った場合は最初から入力を受け付ける。
- E2E はフォームを開くときの JavaScript 配信を一時止めて無効な状態を確かめる。配信を再開し、新規の保存、下書きの公開、公開ページでの本文表示を確かめる。
