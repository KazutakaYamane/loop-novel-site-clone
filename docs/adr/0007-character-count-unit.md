# 0007 作品の文字数の数え方

- 状態: 採用
- 日付: 2026-11-26

## 背景

作品とエピソードの文字数を表示する。空白や改行を数えるかどうか、サロゲートペアや結合文字をどう扱うかで、同じ本文でも数が変わる。

## 決定

作品の文字数は、空白類(半角と全角の空白、改行、タブ)を除いた Unicode の文字数(コードポイントの数)で数える。

## 理由

- 書き手が気にするのは本文として読まれる文字の量で、段落の区切りや字下げの空白は含めないほうが実感に合う。
- バイト数や UTF-16 のコード単位で数えると、漢字や絵文字で数が膨らむ。コードポイントで数えれば、backend(`mb_strlen`)と frontend で同じ数を出せる。

## 結果

- 文字数を出す処理は、backend と frontend で同じ規則に従う。
