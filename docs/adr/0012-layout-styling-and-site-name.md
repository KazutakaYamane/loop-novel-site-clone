# 0012 画面の組み方(CSS Modules)とクローンのサイト名

- 状態: 採用
- 日付: 2026-11-27

## 背景

要件書 5 章は、すべての画面の見た目を PC とスマートフォンの両方の幅でカクヨムに合わせ、カクヨムの CSS・画像・フォントはコピーせず採取した値から書くことを求める。ロゴとバナーは同じ寸法のダミーにし、サイト名を「カクヨム」にしない。すべてのページに `noindex` を付け、フッターに非公式のクローンである旨を出す。#119 で全ページ共通のヘッダーとフッターを初めて作るので、スタイルの書き方とサイト名を決める必要がある。

## 決定

- スタイルは CSS Modules で書く。部品ごとに `Xxx.module.css` を `Xxx.tsx` の隣に置き、部品は `app/_components/<Name>/` に置く。Tailwind などの道具は足さない(`scripts/loop/dependencies.md` に無く、Next.js の標準だけで足りるため)。
- 色・内容の幅・ヘッダーの高さは `app/globals.css` の `:root` に CSS 変数として置き、部品はそれを使う。値は `docs/kakuyomu-reference/` に採取したものから書く。
- PC とスマートフォンの切り替えは `max-width: 767px` のメディアクエリで行う。カクヨムの切り替えの幅は採取していないので、タブレット以上を PC の組み方にする一般的な境目にした。PC とスマートフォンで DOM は分けず、同じ要素を CSS で組み替える(テストと支援技術から見える要素を 1 つにするため)。
- ヘッダーはカクヨムと同じく `position: fixed` にし、`body` の上の余白をヘッダーの高さ(PC 50px、スマートフォン 79px)にする。
- サイト名は「ヨミカキ」にする。ロゴはカクヨムと同じ 130×25 のダミーの SVG(`public/images/logo.svg`)で、スマートフォンでは 83×16 に縮める。
- `noindex` はルートの `metadata.robots` に `{ index: false }` を書き、すべてのページに付ける。
- カクヨムのヘッダーとフッターにある導線のうち、ランキング・検索・ジャンル一覧(AC-F7-3)と、まだ無い機能(ネクスト、書籍化作品、フッターのリンクの列)は出さない。導線は、その機能を作る issue が足す。

## 結果

- 画面を足す issue は、同じ CSS 変数と `max-width: 767px` の境目を使う。
- 文字の描画は、`body` のフォントの並びのうち、動いている環境にあるものになる。見た目の比較は Playwright のイメージにあるフォントで撮る(docs/adr/0007)。
