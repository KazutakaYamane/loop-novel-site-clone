# 0024 読者向けの作品と話は公開済みの話から決める

- 状態: 採用
- 日付: 2026-11-27

## 背景

#125 では作品ページ、話ページ、目次を作る。作品に公開状態の列はなく、話が公開状態を持つ。ワークスペースで所有者が下書きを読む経路は ADR 0020 と 0021 で定めている。

## 決定

- 読者向けの `GET /api/works/{work}` は、公開済みの話を 1 つ以上持つ作品を返す。この条件は `Work::published()` として新着の取得からも使えるようにする。目次は公開済みの話の ID とタイトルを作成順で返す。
- `GET /api/works/{work}/episodes/{episode}` は、指定した作品に属する公開済みの話だけを返す。前後の話を探すときも同じ公開条件で絞り、作成順で最も近い話を選ぶ。
- どちらの API もゲスト、他の利用者、作品の所有者に同じ結果を返す。公開条件を満たさないときや ID の組み合わせが存在しないときは 404 を返す。所有者はワークスペースで下書きを読む。
- Next.js の描画と OGP は読者向け API の同じ応答を使う。取得はリクエストごとに行い、ブラウザの cookie を転送しない。本文は入力された空白と改行を保ち、React のテキストとして表示する。
- OGP の作品ページの説明には紹介文、キャッチコピー、タイトルの順で最初にあるものを使う。話ページのタイトルは「話のタイトル - 作品名」とし、説明には作品の紹介文を使う。紹介文が空のときは OGP のタイトルを使う。

## 結果

- 下書きは読者向け API の本文、目次、前後のリンク、OGP に含まれない。
- 作品の目次を読むときに話の本文は取得しない。話ページではその話の本文と前後の話の ID を取得する。
